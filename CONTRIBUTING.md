# Contributing

Run Node 22+, `npm ci`, `npm run check`, `npm test` and `npm run secrets:check`. Offline CI makes no paid model calls. Share synthetic examples and numeric measurements. Keep input values supplied by the task and UI observations separate from fixture oracle state.

Freeze code and manifests before comparative runs. Preserve failed attempts and unsupported inputs. Do not convert unsupported visual input through an undisclosed model or OCR. Different systems and decision models require separate comparisons.
